# ExecPlan Workflow

ExecPlans are living implementation plans for substantial work.

## Substantial Work

Create or update an ExecPlan for greenfield bootstrap, new end-to-end capabilities, architecture changes, candidate model/schema changes, content pipeline changes, localization architecture, LaTeX/PDF changes, external AI integrations, CI/release infrastructure, significant refactors, or work spanning several components.

Small local bug fixes may be implemented directly when the intended behavior is already documented.

## Locations

- Active plans: `docs/exec-plans/active/`
- Completed plans: `docs/exec-plans/completed/`

## Contents

Each plan should state objective, scope, milestones, validation, acceptance criteria, decisions, and progress. Update the active plan as implementation proceeds and move it to completed only after validation and documentation are done.
