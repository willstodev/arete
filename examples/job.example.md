# Example Job Description

## Role

Backend TypeScript Engineer

## Company Context

The team builds customer-facing APIs and internal platform services for a growing SaaS product. Engineers work closely with product, support, and operations teams to improve reliability, developer experience, and delivery quality.

## Responsibilities

- Build and maintain Node.js services written in TypeScript.
- Design REST APIs with clear request and response contracts.
- Add runtime validation for untrusted input.
- Improve PostgreSQL-backed workflows and data import processes.
- Expand automated test coverage for critical service behavior.
- Maintain CI/CD checks that catch regressions before deployment.
- Collaborate with product managers and support teams to clarify edge cases.
- Write maintainable code and practical technical documentation.

## Requirements

- Professional experience with TypeScript and Node.js.
- Experience building or maintaining REST APIs.
- Practical PostgreSQL experience.
- Familiarity with integration testing and regression testing.
- Comfort working in GitHub Actions or a similar CI/CD environment.
- Ability to explain technical tradeoffs clearly.

## Preferred

- Experience migrating JavaScript services to TypeScript.
- Experience with runtime schema validation.
- Experience improving failure diagnostics for internal users or customers.
- Evidence of cross-functional collaboration.

## Recruiter Signals

- Clear examples of ownership.
- Bullets that show action and result, not only responsibility.
- Technologies named in context.
- Concrete metrics where the candidate actually knows them.
- No exaggerated claims that fail under interview follow-up.

## ATS Keywords

TypeScript, Node.js, REST APIs, PostgreSQL, runtime validation, integration testing, regression testing, CI/CD, GitHub Actions, API design, failure diagnostics, developer tooling, cross-functional collaboration.
